# Paleblood

A 100% native source port of Bloodborne: every function of the original
executable replaced by readable source that builds and runs on its own. This is
a functional decompilation, not a matching one: a replacement has to behave the
same (checked by `tools/verify.py`), not compile to the same bytes.

## Legal

- **No game files, ever.** This repository contains no code, assets, binaries,
  decompiler output or extracted data from the game, and never will. What it holds is
  newly written source, tools and documentation.
- **Bring your own copy.** To build, run or verify anything you need your own legally
  obtained copy of Bloodborne (CUSA03173, EU) with the 1.09 update, dumped from your own
  console. The target is pinned by hash ([`target.sha256`](target.sha256)).
- **Not affiliated.** This is a fan project. It is not affiliated with, endorsed by or
  sponsored by Sony Interactive Entertainment or FromSoftware. Bloodborne and related names
  are trademarks of their respective owners.
- `tools/check_no_game_data.py` runs in the pre-commit hook and in CI and rejects anything
  that looks like game data. See [CONTRIBUTING.md](CONTRIBUTING.md).

## Layout

| Path | What |
|---|---|
| `runtime/` | Generic PS4 layer. Nothing specific to this game. |
| `game/<system>/` | Replacement code, one directory per game system. |
| `game/hooks.csv` | Hook registry: original address to replacement. |
| `symbols/` | `functions.csv` (what we track) and `ghidra_functions.csv` (the denominator). |
| `tools/` | `verify.py`, `progress.py`, validators, hooks. |
| `third_party/` | `bbport`, the runtime that loads the original executable and our replacements (a GPL-2.0-or-later fork). |
| `docs/` | [Onboarding](docs/ONBOARDING.md), [Ghidra setup](docs/GHIDRA.md), [Architecture](docs/ARCHITECTURE.md), [verify.py design](docs/VERIFY.md). |

Documentation per system: [`docs/systems/`](docs/systems/) (generated; edits go through issues and pull requests).

## Build

```
cmake -S . -B build && cmake --build build -j && ctest --test-dir build --output-on-failure
tools/install_hooks.sh
```
